# Keyboard Shortcuts

This document lists all keyboard shortcuts available in PolyCode IDE.

## File Operations

| Shortcut | Mac | Description |
|----------|-----|-------------|
| `Ctrl+N` | `Cmd+N` | Create new file |
| `Ctrl+O` | `Cmd+O` | Open file |
| `Ctrl+S` | `Cmd+S` | Save file |
| `Ctrl+Shift+S` | `Cmd+Shift+S` | Save file as |
| `Ctrl+W` | `Cmd+W` | Close file |

## Editor Operations

| Shortcut | Mac | Description |
|----------|-----|-------------|
| `Ctrl+Z` | `Cmd+Z` | Undo |
| `Ctrl+Y` | `Cmd+Y` | Redo |
| `Ctrl+F` | `Cmd+F` | Find |
| `Ctrl+H` | `Cmd+H` | Find and replace |
| `Shift+Alt+F` | `Shift+Alt+F` | Format code |

## IDE Operations

| Shortcut | Mac | Description |
|----------|-----|-------------|
| `Ctrl+\`` | `Cmd+\`` | Toggle terminal |
| `Ctrl+B` | `Cmd+B` | Toggle sidebar |
| `Ctrl+,` | `Cmd+,` | Open settings |
| `Ctrl+/` | `Cmd+/` | Show keyboard shortcuts |
| `Ctrl+R` | `Cmd+R` | Run code |

## AI Operations

| Shortcut | Mac | Description |
|----------|-----|-------------|
| `Ctrl+Shift+G` | `Cmd+Shift+G` | Generate code |
| `Ctrl+Shift+E` | `Cmd+Shift+E` | Edit code |
| `Ctrl+Shift+A` | `Cmd+Shift+A` | Analyze code |
| `Ctrl+I` | `Cmd+I` | Toggle AI panel |

## Customization

You can customize keyboard shortcuts in the Settings panel. To do this:

1. Open Settings (`Ctrl+,` / `Cmd+,`)
2. Navigate to "Keyboard Shortcuts"
3. Click on a shortcut to change it
4. Press your desired key combination
5. Save your changes

## Conflict Detection

The system automatically detects keyboard shortcut conflicts. If you assign the same key combination to multiple shortcuts, you'll see a warning in the settings panel.

## Platform Differences

- **Windows/Linux**: Uses `Ctrl` modifier
- **macOS**: Uses `Cmd` modifier

Some shortcuts may have platform-specific variations for consistency with the operating system's conventions.
